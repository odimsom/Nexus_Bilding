Nexus Bilding is a modern Enterprise Resource Planning (ERP) system designed following Onion Architecture and Domain-Driven Design (DDD) principles. It is structured with high cohesion, low coupling, and scalability in mind.

## Architecture Highlights
- **Domain-Driven Design (DDD)**
- **Onion Architecture**
- **Strict Modularity** (Administration, Security, Inventory, etc.)
- **Angular** for the Web Presentation layer
